# private-ai-assistant 0.1.0

## Changes
- First release: React frontend, Flask API and LangChain agent (Amazon Bedrock) in one ECS Fargate service.
- Internal Application Load Balancer with Amazon Cognito sign-in; no public application endpoint.
- Deploys into an existing VPC using two or three private subnets.
- KMS-encrypted CloudWatch Logs and application secret; alarms published to a product SNS topic.

## Upgrade
First release: install by creating a new CloudFormation stack from the 0.1.0 template.

## Breaking changes
None.
